# 单位



## 宽度

* width
  * `auto`
  * `min-content` 和 `max-content`
  * `fit-content`。长度适应内容
  * `vw`、`vh`、`vmin`、`vmax`。
  * `vmin` 和 `vmax`。
* min-width
* max-width

### `vw`、`vh`、`vmin`、`vmax`

| 单位   | 基准                               | 横竖屏切换 |
| :----- | :--------------------------------- | :--------- |
| `vw`   | 视口宽度                           | 会变       |
| `vh`   | 视口高度                           | 会变       |
| `vmin` | 宽度和高度中**较小**的那个作为基准 | 不变       |
| `vmax` | 宽度和高度中**较大**的那个作为基准 | 不变       |

流式字体设置，让浏览器自动缩放时可自动变大变小

```css
font-size: clamp(16px, 2.5vmin, 24px);
```

## 经验

一般 `rem` 设置字号，用 `px` 设置边框，用 `em` 设置其他大部分属性，尤其是内边距、外边距和圆角（不过我有时用百分比设置容器宽度）。
