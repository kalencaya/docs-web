# 选择器

## 类型

下面选择器类型的优先级从上往下依次递减：

* id 选择器
* 类选择器，属性选择器（`[type="radio"]`），伪类（`:hover`）
* 标签选择器，伪元素（`::before`）

通配符选择器（`*`）和关系选择器（`+`、`>`、`~`、` `、`||`）和否定伪类（`:not()`）对优先级没有影响。（但是，在 `:not()` 内部声明的选择器会影响优先级）。

## 优先级

* 来源
  * 行内 -> css 文件 -> 浏览器默认
* 优先级。越精确越好，同等优先级下，看数量
  * id -> 类 -> 标签
* 源码位置
  * 后面的覆盖前面的。
* `!important`。`!important` 声明将覆盖任何其他声明，应尽量避免使用 `!important`。
  * 覆盖内联样式
  * 覆盖优先级高的选择器


## 继承

CSS 属性定义会说明这个属性是默认继承的还是默认不继承的，无论继承和非继承属性都可以通过 `inherit` 显式声明继承。

当没有为 CSS 属性指定属性时：

* 继承属性。取父元素的同属性的计算值
* 非继承属性。取初始值。即 `initial`
* `unset`。对于继承属性会设置为父元素的同属性的计算值，非继承属性取初始值
